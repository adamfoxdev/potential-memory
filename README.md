# Potential Memory

Isometric action RPG (Godot 4.3+). Placeholder shapes for now; swap in KayKit / Quaternius (CC0) models.

## Run
Open this folder in Godot 4.3+ and press F5. Left-click the floor to move.
In the editor, select `NavigationRegion3D` and click **Bake NavigationMesh** once.

## Layout
- `assets/placeholder/` temporary art, `assets/final/` replacements
- `scenes/`, `scripts/`, `ui/`
- `data/` items, monsters, skills as `Resource` files
